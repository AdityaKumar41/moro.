# PRD review

The platform implements the core storefront → configure/design → checkout → proof approval → production workflow. See PRD-READINESS.md for current coverage, PRD-ACCEPTANCE.md for reproducible evidence and limits, and RELEASE-PLAN.md for remaining engineering/operator work. The original assignment PDF and private acceptance records are excluded from the open-source release.

Sample prices/taxes, placeholder merchant identity, conceptual imagery and raster RGB output must not be represented as approved live commercial or manufacturing configuration. Future Xero/corporate/mobile integrations are extension points. Enterprise acceptance requires actual device/load/security/recovery checks and physical/output/operator sign-off, not an MVP label change.
