# UI direction

Moro uses a cream/ink/vermilion editorial print-studio theme, geometric sans typography and restrained expressive italic accents. Keep public navigation compact, product families equally discoverable, concepts labelled and payment-preview notices discreet. The studio is a focused workspace, with no marketing header/footer around the canvas.

Use visible focus, readable text contrast, touch targets, honest disabled states, named progress stages and recoverable errors. Skeletons should match the layout being loaded. Respect reduced motion. Never use a success toast as a substitute for a confirmed server result.

Decorative accents use the licensed Trazo package; see THIRD_PARTY_NOTICES.md. The generated print-kit scene is concept artwork, not delivered customer work. Full screen-reader, device and zoom acceptance remains a release gate.
