# Customer workspace

The account area combines overview, saved designs, orders, proof approvals and profile settings. Reuse the Moro theme, skeleton structure and accessible status/error messages. A completed gateway redirect is not payment evidence; read the verified server order state and bound polling.

Projects retain configuration, artwork, CSV and owned source-upload metadata. Show preview/empty/search states and preserve stable design identity when reopening. Save before leaving the editor or checking out; account changes must never overwrite another customer's project. Paid orders expose receipt download/email actions. Proof approval requires the current paid ready proof and image readiness.
